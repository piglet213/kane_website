2. 기본 수정 방법

수정 도구

메모장(Windows) 또는 텍스트 편집기 아무 거나 사용 가능합니다.

수정 순서

수정할 HTML 파일을 우클릭 → 연결 프로그램 → 메모장으로 열기
Ctrl+F로 수정할 텍스트 검색
텍스트 수정 (한국어/독일어/영어 3개 모두 수정)
Ctrl+S로 저장
브라우저에서 파일을 열어 확인 (또는 F5 새로고침)
🚨 절대 하지 마세요:
• < > " 같은 기호를 삭제하거나 변경하지 마세요
• style= class= onclick= 같은 코드를 건드리지 마세요
• 따옴표(") 안의 텍스트만 수정하세요
💡 팁: 수정 전에 항상 파일을 복사해서 백업해 두세요. 실수하면 백업 파일로 되돌릴 수 있습니다.

3개 국어 수정 규칙

모든 텍스트는 3개 국어로 되어 있습니다. 아래 형식을 따릅니다:

data-lang-ko="한국어 텍스트" data-lang-de="독일어 텍스트" data-lang-en="영어 텍스트"

따옴표 안의 텍스트만 수정하세요. 3개 언어 모두 수정해야 합니다.

예시 — "설립연도"를 "창립연도"로 바꾸고 싶을 때:

수정 전: data-lang-ko="설립연도" data-lang-de="Gründungsjahr" data-lang-en="Founded"
수정 후: data-lang-ko="창립연도" data-lang-de="Gründungsjahr" data-lang-en="Founded"

3. 홈페이지 수정 가이드

Kane_HomePage_V7.html

3-1. 통계 숫자 변경

Ctrl+F로 stat-number 검색

<span class="stat-number">30+</span>

30+ 부분을 원하는 숫자로 변경:

<span class="stat-number">50+</span>
현재 값설명검색어
2024설립연도2024
30+소속 예술가 수30+
5활동 도시 수>5<
12+프로젝트 수12+

3-2. 팀원 추가

Ctrl+F로 team-grid 검색. 기존 팀원 카드 하나를 복사해서 바로 아래에 붙여넣고 내용을 수정합니다.

기존 팀원 카드 형식:

<div class="team-card">
  <div class="team-photo">
    <div class="photo-bg" style="background:linear-gradient(135deg,#1a1a2e,#16213e,#0f3460)"></div>
  </div>
  <div class="team-info">
    <div class="team-role" 
      data-lang-ko="직책" 
      data-lang-de="Position" 
      data-lang-en="Position">직책</div>
    <div class="team-name" 
      data-lang-ko="이름" 
      data-lang-de="Name" 
      data-lang-en="Name">이름</div>
    <p class="team-bio" 
      data-lang-ko="소개" 
      data-lang-de="Bio" 
      data-lang-en="Bio">소개</p>
  </div>
</div>
💡 팁: 그라데이션 색상을 바꾸고 싶으면 linear-gradient 안의 색상 코드를 변경하세요. 색상 코드는 htmlcolorcodes.com에서 찾을 수 있습니다.

3-3. 연혁(타임라인) 추가

Ctrl+F로 timeline 검색. 마지막 timeline-item 바로 뒤에 아래 코드를 붙여넣으세요:

<div class="timeline-item">
  <span class="timeline-year">2027</span>
  <div class="timeline-content">
    <h4 data-lang-ko="새 이벤트 제목" 
        data-lang-de="Neuer Titel" 
        data-lang-en="New Title">새 이벤트 제목</h4>
    <p data-lang-ko="설명 텍스트" 
       data-lang-de="Beschreibung" 
       data-lang-en="Description">설명 텍스트</p>
  </div>
</div>

4. 매거진 수정 가이드

Kane_Magazine_V1.html

4-1. 새 기고글 추가 ⭐ (가장 자주 할 작업)

Ctrl+F로 var articles=[ 검색. [ 바로 다음 줄에 아래 코드를 붙여넣으세요:

{id:7, category:"essay", gradient:gradients[2],
  title:{
    ko:"새 기고글 제목",
    de:"Neuer Artikel Titel",
    en:"New Article Title"
  },
  author:{
    ko:"작가 이름",
    de:"Autorenname",
    en:"Author Name"
  },
  publication:{
    ko:"게재 매체",
    de:"Publikation",
    en:"Publication"
  },
  date:"2026.08",
  body:{
    ko:"<p>한국어 본문을 여기에 작성합니다.</p><p>문단을 나누려면 p 태그로 감싸세요.</p>",
    de:"<p>Deutscher Text hier.</p>",
    en:"<p>English text here.</p>"
  }
},
⚠️ 주의사항:
• id는 기존 글과 겹치지 않는 숫자로 (기존 1~6이면 7부터)
• 맨 마지막에 쉼표(,)를 반드시 넣으세요
• 따옴표 안에 따옴표를 쓰지 마세요

4-2. 카테고리 선택

category 값을 아래 중 하나로 설정:

category 값표시 이름
"criticism"미술비평 / Kunstkritik / Art Criticism
"review"공연리뷰 / Rezension / Performance Review
"essay"에세이 / Essay / Essay
"interview"인터뷰 / Interview / Interview

4-3. 카드 색상(그라데이션) 선택

gradient 값을 아래 중 하나로 설정:

값색상
gradients[0]🔵 네이비 / 다크블루
gradients[1]🟣 보라 / 다크퍼플
gradients[2]🟢 다크그린
gradients[3]🔴 다크레드
gradients[4]🔷 틸 / 다크시안
gradients[5]🟧 다크골드 / 올리브

4-4. 기고글 삭제

삭제할 글의 {id:숫자부터 },까지 전체를 삭제하세요.

4-5. 새 카테고리 추가

예: "칼럼" 카테고리를 추가하고 싶을 때

1) 필터 버튼 추가 — Ctrl+F로 filter-bar 검색. 마지막 filter-btn 뒤에:

<button class="filter-btn" data-filter="column" 
  data-lang-ko="칼럼" data-lang-de="Kolumne" data-lang-en="Column">칼럼</button>

2) 라벨 추가 — Ctrl+F로 getCategoryLabel 검색. interview 줄 뒤에:

,column:{ko:'칼럼',de:'Kolumne',en:'Column'}

6. GitHub 업로드 방법

6-1. 파일 수정 후 GitHub에 반영하기

GitHub 접속 → kane-website repository 열기
수정한 파일 클릭 (예: Kane_Magazine_V1.html)
오른쪽 상단 ✎ 연필 아이콘 클릭
Ctrl+A (전체 선택) → Delete (전체 삭제)
메모장에서 수정한 파일 내용을 Ctrl+A → Ctrl+C (복사)
GitHub 편집 창에 Ctrl+V (붙여넣기)
하단 "Commit changes" 버튼 클릭

6-2. GitHub에서 직접 수정하기 (간단한 텍스트 수정)

GitHub에서 수정할 파일 클릭
✎ 연필 아이콘 클릭
Ctrl+F로 수정할 텍스트 검색
텍스트 직접 수정
"Commit changes" 클릭

6-3. 다른 사람에게 권한 주기

Repository → Settings 탭
왼쪽 메뉴 "Collaborators" 클릭
"Add people" 클릭
상대방 GitHub 아이디 또는 이메일 입력 → 초대

7. 문제 해결

증상원인해결
페이지가 하얀 화면코드가 깨짐 (태그 삭제 등)백업 파일로 복원
배경 이미지 안 보임bg.jpg가 같은 폴더에 없음같은 폴더에 넣기
메뉴 클릭해도 이동 안 됨파일명이 다름파일명 정확히 일치하는지 확인
새 기고글이 안 보임코드 문법 오류 (쉼표 누락 등)쉼표, 따옴표, 중괄호 확인
언어 전환 안 됨data-lang- 속성 오류따옴표가 제대로 닫혔는지 확인
글자가 깨져 보임파일 인코딩 문제메모장 저장 시 인코딩을 UTF-8로 설정
💡 최고의 안전장치: 수정 전에 항상 기존 파일을 복사해서 _backup 폴더에 넣어두세요.
